## About

RCCG Kingdom Diplomats is a youth church in Nigeria. This GitHub organization is where we publish the browser-based tools we build for church events and gatherings, so that other youth groups and churches can use them, learn from them and improve them.

Everything here is built with JavaScript and runs in a web browser. No installation is needed to use the projects.

## Projects

| Project | What it is |
|---|---|
| [bible-family-feud](https://github.com/rccgkd/bible-family-feud) | A stage-ready, Bible-themed Family Feud game for church events. It includes 60 rounds, a dual-window host and answer view, strike and steal logic, and synthesized background music, all in the browser. |
| [bible-trivia-game](https://github.com/rccgkd/bible-trivia-game) | A host-controlled multiplayer Bible trivia game for church gatherings, with lifelines and audience voting. |

## How to use the projects

1. Open the project you want from the table above.
2. Read its page for the latest details on how to start a game.
3. Run the game in a modern web browser on a laptop, projector or phone, depending on the project.

For events, the host controls the game while the audience watches the answer view or takes part from their own devices.

## Get involved

You do not need any special tools to help.

- **Found a bug?** Open the project, click the **Issues** tab, then **New issue**, and describe what happened and what device you used.
- **Have an idea?** Open an issue in the same way and tell us what would make the game better for your group.
- **Want to improve something?** Open a file in the project, click the pencil icon, make your change, and GitHub will guide you to create a pull request.

Please be kind and patient with everyone.
